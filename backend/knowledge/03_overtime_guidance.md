# Overtime Guidance

## Permitted range

Overtime hours submitted for a single period must be zero or greater, and
must not exceed the organisation's overtime ceiling for a single period.
A value above the ceiling is always treated as an error and must be
corrected in the source file -- there is no legitimate reason for a single
period to exceed the ceiling, so this is never something to explain away,
only to fix.

## Unusual but technically permitted overtime

Separately from the hard ceiling, each employee has a typical average
overtime figure based on their recent periods. When a submitted value is
substantially higher than that employee's own average -- for example,
several times their usual hours -- it is flagged for review even though it
is within the permitted ceiling. This is a judgement call, not a hard rule.

## Why this distinction matters

A figure that is technically within range but far above someone's normal
pattern is often a genuine mistake -- for example, a monthly total entered
into a field that expects a weekly figure. It can also be entirely
legitimate, such as genuinely covering extra shifts during a busy period or
covering for absent colleagues.

## What to do about it

If the submitted overtime figure is correct, the submitter should provide a
short explanation so the Payroll Specialist can review and confirm it
before approval. If it is not correct, the submitter should correct the
value in the source file and resubmit rather than sending an explanation.

## What the Payroll Specialist should check

When reviewing an unusual overtime figure, the Specialist should compare it
against the employee's recent history, consider whether any explanation
provided by the department is plausible, and query the department directly
if anything is unclear before approving the submission.
