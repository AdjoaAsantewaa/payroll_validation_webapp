# Department Submitter Responsibilities

## Role summary

A Department Submitter uploads their department's payroll file each cycle,
resolves the issues flagged against it, and answers any queries the
Payroll Specialist raises, so their department's payroll can be approved
and paid on time.

## Before uploading

Check that the file covers every employee who should be paid this period,
that Staff IDs match the employee master data, and that overtime, basic
pay, and allowances are filled in for each row.

## After uploading

Review the list of issues shown immediately after upload. Each one
explains what is wrong and what to do next. Fix what can be fixed in the
source file and upload again -- a new upload replaces the previous version
and is checked again from scratch.

## Issues that are not simple mistakes

Not every flagged issue means the file is wrong. Some -- particularly
unusual overtime -- may be genuinely correct but unusual, in which case an
explanation is more appropriate than a correction. If unsure whether to
correct or explain, treat it as a correction unless there is a specific,
known reason the value is right.

## Answering queries

If the Payroll Specialist sends a query, respond to each item: confirm the
value is correct with a short explanation, or say the file will be
corrected and resubmitted. Do not leave a query unanswered, since the
submission cannot be approved until every item is resolved.

## Scope

A submitter only sees and manages their own department's submission and
employee data. Submitting on behalf of another department, or expecting to
see another department's payroll data, is outside the intended process --
each department is responsible for its own submission.
