# Payroll Correction and Resubmission Procedure

## Two ways an issue gets resolved

A flagged issue is resolved in one of two ways: the submitter corrects the
source file and uploads it again, or the submitter (or the Payroll
Specialist, for judgement-based issues) provides an explanation that the
Specialist accepts as-is.

## Correcting and resubmitting

For factual errors -- a missing value, an unrecognised Staff ID, a
duplicate row, a value outside the permitted range -- the fix is always to
correct the source spreadsheet and upload it again. Uploading a new file
automatically creates a new version of the submission and re-runs every
check from scratch; the previous version is kept as history but stops
counting toward the department's open issues.

## Explaining rather than correcting

For a judgement-based issue -- most commonly an overtime figure that is
unusual but not actually wrong -- correcting the file is not the right
response if the figure is genuinely accurate. Instead, the submitter (or
the person answering a query) should provide a short, specific explanation
of why the figure is correct, so the Payroll Specialist can review it and
decide whether to accept it.

## Queries from the Payroll Specialist

If the Payroll Specialist needs the department to confirm or clarify
something before approving, they send a correction query listing the
specific items. The submitter should respond to each item -- either
confirming the value is correct with an explanation, or saying they will
correct and resubmit. A query does not require every issue in the
submission to be resolved at once; items can be handled one at a time.

## What happens after resubmission

When a corrected file is uploaded, the submission is checked again in full.
Any issue that no longer applies is dropped automatically; the submitter
does not need to do anything extra to have it removed. Only remaining or
new issues need attention.

## Approval

Once every issue on the current version has been accepted, rejected, or
answered, the Payroll Specialist can approve the submission. A submission
with any unresolved issue cannot be approved.
